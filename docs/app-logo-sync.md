# Official app logo synchronization
The approved source paths are in scripts/app-logo-sources.json. PNG bytes are retained unchanged, with Git blob and SHA-256 provenance in docs/app-logo-lock.json. The browser reads same-origin local copies and never accesses GitHub or secrets. AppCore uses its own approved SVG. Unknown applications show a neutral fallback until a source is approved.
The design deployment workflow refreshes the approved icons before browser QA and deployment, and commits changed verified icons to the current development branch. To request a logo-only refresh, update .appcore/logo-sync.json (explicit owner request). The public ExMore branch can be read without a credential. For current private AlTabloh branch changes, configure the optional Actions secret APPCORE_GITHUB_READ_TOKEN with Contents read for the specific source repos; without it, use only exact known blob bytes from the approved published public mirror or verified cache. A changed/unverifiable mirror cannot overwrite a verified icon. No automatic schedule on the development branch is claimed; periodic runs need a default-branch schedule or an authorized external trigger.
